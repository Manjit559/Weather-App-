# ⛅🌍 Weather App 🌦️  

A sleek and interactive **Weather App** 🌡️📱 built with **HTML**, **CSS**, and **JavaScript** ⚡.  
Fetch **real-time weather info** 🌤️ for any city 🏙️ and display it beautifully! 🎨✨  

---

## ✨ Features  

- 🔎 Search for **current weather** by city name 🏙️  
- 🌡️ Displays **temperature, humidity, wind speed** & more 🌬️💧  
- 📱 **Responsive UI** (works on desktop & mobile) 💻📲  
- ⚡ **Fast & lightweight** frontend app  
- 🎯 Built with pure **HTML + CSS + JavaScript**  

---

## 🛠️ Tech Stack  

- 🌐 **HTML** → Structure & layout  
- 🎨 **CSS** → Styling & responsiveness  
- ⚡ **JavaScript** → Logic & API integration  
- ☁️ **OpenWeather API** (or similar) → Real-time weather data
